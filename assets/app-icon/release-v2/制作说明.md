# 九档光学尺寸正式资源

## 来源与制作

- 设计方向沿用已确认的光学校对板；旧提案原图只留本机私有归档。
- 身份沿用黑色圆角底板、独立毛玻璃输入框、左侧淡彩四角星与白色竖光标。右侧没有横杠或文字。
- 正式 PNG 并非裁切生图板或等比缩小一个母稿：16、20、24 使用独立整数像素网格；32、40、48、64、128、256 使用逐档几何规格及原尺寸曲线绘制。
- 像素网格保存为 ./16.pixels.txt、./20.pixels.txt、./24.pixels.txt；曲线原稿保存为各尺寸的 .drawing.xaml。
- 可重现绘制程序位于 ../../../tools/icon-artwork/，无需图像服务或 API Key。程序是开发工具，未加入最终 EXE。
- PNG 均保留外围透明度和不透明黑色底板。小尺寸仅使用 0/255 两种 Alpha，避免插值边缘模糊。

## 资源

- 原生尺寸：16、20、24、32、40、48、64、128、256 像素。
- ./app.ico：九帧 32 位图标，原始 RGBA PNG 帧封装。
- ./preview-enlarged.png：无损、整数倍最近邻放大图。
- ./preview-native-dark.png、./preview-native-light.png：深浅背景上的真实像素尺寸预览。
- ./review-board/composite_result.jpg：使用 image-tools 纵向整理的总览，JPEG 仅用于查看布局，不作为像素校验依据。

## 加载与验收

- 应用资源以 ImageSource 的 URI 转换生成 BitmapFrame，保留九帧 IconBitmapDecoder，不能改回 BitmapImage。
- 原生窗口的 WM_GETICON 大小图标不仅检查存在，还检查实际主体包围盒至少占各边八成，并与对应光学帧一致。
- 主浮窗标题位置依据实际 DPI 选择帧；原生 EXE 图标组保留同一套九档数据。
- 不清理 Windows 图标缓存，不改写用户现有快捷方式或固定按钮。
