# AntigravityPrefix 使用说明

本目录可整体复制使用，无需安装，不需要 API Key 或额外 .NET 运行环境。先退出旧版，再双击 `./AntigravityPrefix.exe`。支持 Windows x64。

1. 在 Antigravity 中选中目标会话，点击浮窗的编辑入口（优先直接点击顶部 Breadcrumb 会话标题打开内联输入框，必要时自动回退至右上角 `More actions` → `Rename`）。
2. 若自动打开受阻，手动点击会话右上角 ⋯ → Rename（或左侧栏会话 ⋯ → Rename），保持内联输入框打开。
3. 状态提示已识别后，点击前缀或清除按钮；提交后核对 Antigravity 实际名称。
4. 设置列表时可添加、标记删除、拖拽排序；顶部勾号按当前活动模式保存，叉号取消。常规态右下角切换按钮可在「个人快照 / 内置默认」间淡入淡出无损切换；编辑态右下角提供「保存为个人快照」（不被更新覆盖）与「保存为内置默认」（更新程序目录 `default-emojis.json` 并在仓库运行环境中同步源码预设）。面板最底部常驻版本号、状态提示与更新图标按钮，非设置状态下也可直接检查与一键自更新。

配置固定在 Windows 系统 LocalApplicationData 下的 `./AntigravityPrefix/emoji-settings.json`，与程序目录及 CodexPrefix 完全隔离。更新时只会通过已校验的新版程序按白名单替换程序目录（若为独立单 EXE 模式则只替换 EXE 与同名 `default-emojis.json`），个人快照 `emoji-settings.json` 与 `settings.json` 不会丢失；不要用默认文件覆盖自己的配置。置顶与更新偏好另存为 `./AntigravityPrefix/settings.json`。

如需迁移电脑，退出工具后复制完整 emoji 配置，包括历史登记和稳定 ID；先备份新电脑已有文件，再覆盖相同用户目录的位置。保持 UTF-8，不删除 emoji 内部字符。

核心改名功能离线执行，不修改 Antigravity 安装文件、数据库或内部状态文件，也不以管理员运行。仅在启动静默检查（可在配置关闭）或点击面板底部更新图标按钮时，才向公开仓库 `areusa/AntigravityPrefix-Release` 发起只读 HTTPS 请求获取清单、校验和与发布文件，经双重 SHA-256 校验后再原子替换并在异常时自动回滚，绝不上传任何本地配置或会话信息。自动打开及原生控件识别受 Antigravity 版本影响；身份不能确认时会停止，不会猜测同名会话。v0.1.5 彻底移除小条跨进程 GWLP_HWNDPARENT 耦合、修复 PlaceAbove 非置顶层 HWND_NOTOPMOST 空操作漏洞并补齐 SWP_NOOWNERZORDER 防护与层级状态日志，同时收敛多屏重定位日志风暴，经 26 小时实机连续运行确认不再触发宿主置顶；v0.1.4 新增底部常驻自更新（启动静默检查与手动检查、双 SHA-256 校验与异常自动回滚）、个人快照/内置默认三按钮双配置与淡入淡出切换、无个人配置初始保护及 `--data-dir` 隔离参数，并完成实机体验与纯净初始态验收；v0.1.3 保留编辑按钮前置防误触并优化主文档缓存、Breadcrumb 标题直开与焦点移开后的后台提交韧性，已在 Antigravity 2.34.0 实机验证；v0.1.2 修复小条模式 `PlaceAbove` 在置顶窗口边界引发的 `WS_EX_TOPMOST` 提权隐患；v0.1.1 已实机验证重命名瞬态恢复、右侧页签共存与持久化流程，后续 Antigravity 升级、IME 与多屏边界仍需实机复测。

识别无响应时会终止本工具的隔离工作进程并允许重新识别。若提示“写入结果待核验”，先检查 Antigravity 的原生名称，关闭原重命名框后再重新打开；工具不会自动重复保存。正常运行时可能看到同名工作进程，退出工具会一并结束。

“诊断”输出可能含可见控件名称，分享前应检查。正常使用不需要打开测试或采样参数。第三方许可见 `./THIRD-PARTY-NOTICES.txt` 和 `./licenses/`，也可在工具内查看。

`./version.json` 记录版本及程序 SHA-256，`./SHA256SUMS.txt` 用于核对本目录文件。发布目录不包含个人预设、测试输出或压缩包。
